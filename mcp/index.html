Use Turnmark with an AI assistant

Convert a swim, look up a published standard, or calculate points from a conversation. Turnmark's MCP server uses the same Rust engine as the web and native apps.

Connect the hosted server

Add a remote MCP server in your assistant or editor:

Server URL
https://mcp.turnmark.app/mcp
Transport
Streamable HTTP
Authentication
None. No API key, account or installation required.

For a portable .mcp.json in current VS Code/Copilot:

{
  "mcpServers": {
    "turnmark": {
      "type": "http",
      "url": "https://mcp.turnmark.app/mcp"
    }
  }
}

Client formats differ. VS Code's editor-specific .vscode/mcp.json uses servers instead of mcpServers. See the VS Code setup guide.

Try a question

“Convert a men's 200 m LCM breaststroke time of 2:16.71 to SCY, and show the source and whether the answer is published or derived.”

The published-factor conversion returns 1:57.29. Ask your assistant to list Turnmark's tools or call get_sources to inspect its bundled editions and coverage.

An interactive conversion card

Hosts that support MCP Apps can show your conversion as a Turnmark card. Change the time or comparison course and choose Update comparison. The card uses the same calculation tool, preserves the original swim and source, and follows the host's light or dark appearance. Text-only clients still receive the full result.

Use the same server URL. The card requests no device or network permissions; your host still controls rendering, tool calls and links. Rendering depends on the host and surface. The official browser bridge is verified; specific ChatGPT, Claude and VS Code versions still need a visual acceptance pass. The published local package 0.2.0 includes the same card with text and structured results for clients that do not render Apps.

Available tools

convert_swim
Convert an entered event to an explicit course, preserving destination distance and result kind.
adjust_altitude
Apply the published altitude adjustment at an explicit elevation and unit.
get_youth_standards
Look up published youth motivational standards.
get_masters_target
Look up a USMS Nationals benchmark or a precise missing-data result.
get_world_points
Calculate points for an original metric swim.
get_sources
Inspect engine version, source editions, coverage and attribution.

The MCP reference includes argument examples, structured results and offline setup. For offline stdio, install @turnmark/mcp@0.2.0; it includes the SDK dependency and provides the turnmark-mcp executable. No Rust toolchain is needed to use the installed package.

Inputs, privacy and missing data

The tools are read-only and accept explicit calculation inputs. They cannot read saved swims, profiles, files or browser history, and do not store a personal swim history. Remote requests are processed by Cloudflare; use local stdio when inputs should stay on your device.

Published snapshots are not live records. Keep source editions and available, unavailable and invalid outcomes visible. Missing targets stay missing. Converted estimates are not recorded performances, and qualifying targets do not confirm meet-entry eligibility.

Connection troubleshooting

  • 405 in a browser is expected: this URL accepts MCP POST requests, not ordinary page navigation.
  • On 429, honor Retry-After. Avoid rapid automatic retries.
  • The service runs on Cloudflare Free and can temporarily be unavailable. Offline stdio and SDK calculations remain available.
